# Idea Drop Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build an in-app "Idea Drop" inbox on the editorial dashboard where admins/sub-admins paste rich text + images, address it (always to Adnan, optionally wider), and Adnan triages in-app and exports everything to local Markdown for Claude Code.

**Architecture:** A new Firestore `ideas` collection (client-side Web SDK, mirroring the existing `feedback` pattern), images stored hybrid (tiny pasted → inline base64; larger/attached → R2 via a new presigned-PUT route on the existing `dataApi` Cloud Function), canonical body stored as sanitized Markdown (Tiptap → Turndown), rendered with `react-markdown` + `rehype-raw` + `rehype-sanitize`. A content-repo Python script exports the collection to dated Markdown. No email, no new secrets.

**Tech Stack:** Next.js 16 (static export), Firebase Auth + Firestore, Cloudflare R2 behind a Firebase Cloud Function, Tiptap (ProseMirror), Turndown, react-markdown, vitest + @testing-library/react + @firebase/rules-unit-testing.

**Reference spec:** `docs/superpowers/specs/2026-06-08-idea-drop-design.md`

## Key design decisions locked by this plan (read first)

1. **Image R2 keys** use the prefix `images/ideas/<ideaId>/<filename>`. Reads need **no** server change — `images/` is already in `RESOLVE_PREFIXES`. Only **upload (PUT)** is new.
2. **Image references in Markdown** use a token URL of the form `r2:images/ideas/<id>/<file>` (the literal string `r2:` + the R2 key). Inline tiny images use a normal `data:image/...;base64,...` URL. The renderer and copy-serializer branch on these two prefixes.
3. **`ideaId` is minted client-side before upload** via `doc(collection(db,'ideas'))` so image keys are stable across upload-then-save.
4. **Inbox queries are decomposed into per-access-path queries** (author / all_approved / all_sub_admins / array-contains-me) and merged client-side, because Firestore rejects a `list` query that reads a rule field it does not constrain (the lesson already documented in `firestore.rules` for `feedback`). Admin runs a single unconstrained query.
5. **Author edits are field-limited** in the rules: an author may change only `title`/`bodyMarkdown`/`r2Images`/`updatedAt`/`editedAt`; `status`/`tags`/`visibility`/`recipients`/`author` are admin-only after create.

- [ ] **Step 3: Implement**

IMPORTANT — do **not** register a Turndown rule keyed on `TABLE` for the nested-table case: a custom `addRule` whose filter names `TABLE` shadows the gfm table rule for *every* table (even when the filter returns false), so simple tables stop converting to pipe tables. Instead, **pre-process the DOM**: pull each top-level nested-containing table out, leave a placeholder, run Turndown (gfm owns the remaining simple tables untouched), then splice the raw HTML back in.

```ts
import TurndownService from 'turndown'
import { gfm } from 'turndown-plugin-gfm'

// Token must be markdown-INERT: Turndown escapes `_`/`*`/etc. in text nodes
// (e.g. `a_b` -> `a\_b`), which would break a literal string match on splice-back.
// Use letters+digits only so the token survives Turndown verbatim.
const PLACEHOLDER = (i: number) => `xxIDEANESTEDTABLExx${i}xx`

/**
 * Replace each top-level table that contains a nested table with a text
 * placeholder, returning the stripped HTML and the stash of raw table HTML.
 * "Top-level" = a nested-containing table not itself inside another table, so
 * we keep the whole outer structure as one raw-HTML block.
 */
function extractNestedTables(html: string): { html: string; stash: string[] } {
  const doc = new DOMParser().parseFromString(html, 'text/html')
  const stash: string[] = []
  const tables = Array.from(doc.querySelectorAll('table'))
  for (const table of tables) {
    const containsTable = table.querySelector('table') !== null
    const insideTable = table.parentElement?.closest('table') != null
    if (containsTable && !insideTable) {
      const placeholder = doc.createElement('p')
      placeholder.textContent = PLACEHOLDER(stash.length)
      stash.push(table.outerHTML)
      table.replaceWith(placeholder)
    }
  }
  return { html: doc.body.innerHTML, stash }
}

function makeService(): TurndownService {
  const td = new TurndownService({
    headingStyle: 'atx',
    codeBlockStyle: 'fenced',
    bulletListMarker: '-',
    br: '\\', // hard break marker → backslash + newline
  })
  td.use(gfm) // simple tables → GFM pipe tables; alignment/style attrs ignored natively

  // Image: prefer the R2 key token when present (otherwise the src, incl. data: URIs).
  td.addRule('ideaImage', {
    filter: 'img',
    replacement: (_content, node) => {
      const el = node as Element
      const alt = el.getAttribute('alt') ?? ''
      const key = el.getAttribute('data-r2-key')
      const src = el.getAttribute('src') ?? ''
      const url = key ? `r2:${key}` : src
      return url ? `![${alt}](${url})` : ''
    },
  })

  return td
}

/** Convert sanitized editor HTML to canonical Markdown. */
export function htmlToMarkdown(html: string): string {
  const { html: stripped, stash } = extractNestedTables(html)
  let md = makeService().turndown(stripped)
  stash.forEach((raw, i) => {
    // Turndown wraps the placeholder paragraph as plain text on its own line.
    md = md.replace(PLACEHOLDER(i), `\n\n${raw}\n\n`)
  })
  return md.trim()
}
```

NOTE on the environment: `DOMParser` is available in the browser and in the vitest jsdom environment (this repo's `vitest.config.ts` sets `environment: 'jsdom'`), so `extractNestedTables` runs in both.

```ts
import { unified } from 'unified'
import remarkParse from 'remark-parse'
import remarkGfm from 'remark-gfm'
import remarkRehype from 'remark-rehype'
import rehypeRaw from 'rehype-raw'
import rehypeStringify from 'rehype-stringify'

export interface ResolvedImage { dataUri: string; bytes: number }
export type ImageResolver = (key: string) => Promise<ResolvedImage>

export interface ClipboardPayload { html: string; text: string }

/** Total base64 budget for a single copy (8 MB of inlined images). */
export const MAX_INLINE_BYTES = 8 * 1024 * 1024

const R2_PREFIX = 'r2:'

/** Render markdown to HTML, inlining r2: images as base64 within a size budget. */
export async function buildClipboardPayload(
  markdown: string,
  resolveImage: ImageResolver,
): Promise<ClipboardPayload> {
  // 1. Collect r2: image keys referenced in the markdown.
  const keys = Array.from(markdown.matchAll(/!\[[^\]]*\]\(r2:([^)\s]+)\)/g)).map((m) => m[1])

  // 2. Resolve them to base64, honouring the byte budget.
  const map = new Map<string, string>() // key -> data URI
  let spent = 0
  for (const key of keys) {
    if (map.has(key)) continue
    const { dataUri, bytes } = await resolveImage(key)
    if (dataUri && spent + bytes <= MAX_INLINE_BYTES) {
      map.set(key, dataUri)
      spent += bytes
    }
  }

  // 3. Replace r2: tokens with resolved data URIs (or strip the token to ''),
  //    leaving data: URIs untouched.
  const replaced = markdown.replace(/(!\[[^\]]*\]\()r2:([^)\s]+)(\))/g,
    (_full, pre, key, post) => `${pre}${map.get(key) ?? ''}${post}`)

  // 4. Render to HTML (rehype-raw so embedded HTML tables survive).
  const file = await unified()
    .use(remarkParse)
    .use(remarkGfm)
    .use(remarkRehype, { allowDangerousHtml: true })
    .use(rehypeRaw)
    .use(rehypeStringify, { allowDangerousHtml: true })
    .process(replaced)

  return { html: String(file), text: markdown }
}
```

NOTE: `unified`, `remark-parse`, `remark-rehype`, `rehype-stringify` were installed explicitly in Chunk 1 Task 1, so these imports resolve as declared (not transitive) deps.

```ts
export const INLINE_THRESHOLD = 50 * 1024 // 50 KB

export function safeFilename(name: string): string {
  const base = name.split(/[\\/]/).pop() ?? 'image'
  return base.replace(/[^a-zA-Z0-9._-]/g, '_')
}

export type RoutedImage =
  | { kind: 'inline'; dataUri: string }
  | { kind: 'r2'; token: string; key: string; filename: string; contentType: string }

export interface RouteCtx {
  ideaId: string
  upload: (file: File, key: string) => Promise<void>
  toDataUri: (file: File) => Promise<string>
}

export async function routeImage(file: File, ctx: RouteCtx): Promise<RoutedImage> {
  if (file.size < INLINE_THRESHOLD) {
    return { kind: 'inline', dataUri: await ctx.toDataUri(file) }
  }
  const filename = safeFilename(file.name)
  const key = `images/ideas/${ctx.ideaId}/${filename}`
  await ctx.upload(file, key)
  return { kind: 'r2', token: `r2:${key}`, key, filename, contentType: file.type || 'application/octet-stream' }
}

/** Browser helper: File -> data URI (kept here for the composer to pass in). */
export function fileToDataUri(file: File): Promise<string> {
  return new Promise((resolve, reject) => {
    const r = new FileReader()
    r.onload = () => resolve(String(r.result))
    r.onerror = () => reject(r.error)
    r.readAsDataURL(file)
  })
}
```

  title?: string; bodyMarkdown: string; r2Images: R2Image[]

/** Dedupe by id, newest-first; a null createdAt (pending write) sorts first. */
export function mergeAndSort(lists: Idea[][]): Idea[] {
  const byId = new Map<string, Idea>()
  for (const list of lists) for (const i of list) byId.set(i.id, i)
  const ms = (i: Idea) => (i.createdAt ? i.createdAt.toMillis() : Number.MAX_SAFE_INTEGER)
  return [...byId.values()].sort((a, b) => ms(b) - ms(a))
}

function snapToIdeas(snap: { docs: { id: string; data: () => object }[] }): Idea[] {
  return snap.docs.map((d) => ({ id: d.id, ...(d.data() as object) }) as Idea)
}

/** Subscribe to all ideas the viewer may see, via per-access-path queries. */
export function useInboxIdeas(role: AllowStatus, email: string): Live<Idea[]> {
  const [lists, setLists] = useState<Record<string, Idea[]>>({})
  const [loading, setLoading] = useState(true)
  const [error, setError] = useState<Error>()

  useEffect(() => {
    if (!email) return
    const col = collection(db, 'ideas')
    const isAdmin = role === 'admin'
    const isSub = role === 'sub_admin'

    // Admin: one unconstrained query (rule allows via isAdmin()).
    const queries: { key: string; q: ReturnType<typeof query> }[] = isAdmin
      ? [{ key: 'all', q: query(col, orderBy('createdAt', 'desc')) }]
      : [
          { key: 'mine', q: query(col, where('author', '==', email), orderBy('createdAt', 'desc')) },
          { key: 'approved', q: query(col, where('visibility', '==', 'all_approved'), orderBy('createdAt', 'desc')) },
          { key: 'specific', q: query(col, where('recipients', 'array-contains', email), orderBy('createdAt', 'desc')) },
          ...(isSub ? [{ key: 'subs', q: query(col, where('visibility', '==', 'all_sub_admins'), orderBy('createdAt', 'desc')) }] : []),
        ]

    const unsubs = queries.map(({ key, q }) =>
      onSnapshot(q,
        (snap) => { setLists((p) => ({ ...p, [key]: snapToIdeas(snap) })); setLoading(false) },
        (err) => { setError(err as Error); setLoading(false) }))
    return () => unsubs.forEach((u) => u())
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, [role, email])

  return { data: mergeAndSort(Object.values(lists)), loading, error }
}

export function useIdeaReads(email: string): Record<string, boolean> {
  const [seen, setSeen] = useState<Record<string, boolean>>({})
  useEffect(() => {
    if (!email) return
    return onSnapshot(doc(db, 'idea_reads', email),
      (d) => setSeen(((d.data() as { seen?: Record<string, boolean> })?.seen) ?? {}))
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, [email])
  return seen
}

export async function markIdeaSeen(email: string, id: string) {
  await setDoc(doc(db, 'idea_reads', email), { seen: { [id]: true } }, { merge: true })
}

// NOTE: this re-subscribes via useInboxIdeas (so the Topbar badge + the /ideas
// page each mount the per-access-path listeners). The Firestore Web SDK shares
// the underlying query listeners, and idea volume is tiny, so the duplication is
// acceptable for v1; revisit with a shared context only if the inbox grows.
export function useUnreadIdeaCount(role: AllowStatus, email: string): number {
  const { data } = useInboxIdeas(role, email)
  const seen = useIdeaReads(email)
  return data.filter((i) => !seen[i.id]).length
}

CRITICAL: `react-markdown` runs its own `defaultUrlTransform` on every `src` BEFORE the custom `img` component or the sanitizer see it, and that transform allows only `http/https/irc/ircs/mailto/xmpp` — it rewrites `r2:` and `data:` URLs to `''`, so without an explicit `urlTransform` every image silently vanishes. Pass a `urlTransform` that lets `r2:`/`data:` through.

```tsx
'use client'
import ReactMarkdown, { defaultUrlTransform } from 'react-markdown'
import remarkGfm from 'remark-gfm'
import rehypeRaw from 'rehype-raw'
import rehypeSanitize, { defaultSchema } from 'rehype-sanitize'
import { useResolved } from '@/lib/useResolved'

const R2 = 'r2:'

// react-markdown strips non-web URL schemes by default; preserve r2:/data: so
// the custom <img> resolver and inline base64 images survive.
function ideaUrlTransform(url: string): string {
  if (url.startsWith('r2:') || url.startsWith('data:')) return url
  return defaultUrlTransform(url)
}

// Allow tables + data: image URLs through the sanitizer.
const schema = {
  ...defaultSchema,
  tagNames: [...(defaultSchema.tagNames ?? []), 'table', 'thead', 'tbody', 'tr', 'td', 'th'],
  protocols: { ...defaultSchema.protocols, src: [...(defaultSchema.protocols?.src ?? []), 'data', 'r2'] },
}

function IdeaImg(props: { src?: string; alt?: string }) {
  const src = props.src ?? ''
  const isR2 = src.startsWith(R2)
  const key = isR2 ? src.slice(R2.length) : ''
  const resolved = useResolved(isR2 ? [key] : [])
  if (isR2) {
    const url = resolved[key]
    if (!url) return <span aria-busy="true" className="text-brand-ink/40">loading image…</span>
    // eslint-disable-next-line @next/next/no-img-element
    return <img src={url} alt={props.alt ?? ''} className="max-w-full rounded" />
  }
  // eslint-disable-next-line @next/next/no-img-element
  return <img src={src} alt={props.alt ?? ''} className="max-w-full rounded" />
}

export function IdeaMarkdown({ markdown }: { markdown: string }) {
  return (
    <div className="prose prose-sm max-w-none">
      <ReactMarkdown
        remarkPlugins={[remarkGfm]}
        rehypePlugins={[rehypeRaw, [rehypeSanitize, schema]]}
        urlTransform={ideaUrlTransform}
        components={{ img: IdeaImg }}
      >
        {markdown}
      </ReactMarkdown>
    </div>
  )
}
```
